Duskio Support

Answers for setup, appearance, themes, and pages that still look too bright. Duskio is built for Safari on iPhone and iPad.

Getting Started

How do I enable Duskio?

Install and open Duskio, then open Safari. From Safari’s page or extensions menu, open Manage Extensions and enable Duskio. Allow website access, preferably for all websites, then return to a webpage and open the Duskio popup. A full walkthrough is on the setup guide.

Why is a website still light?

Check that Duskio is enabled, that Safari granted website access, and that This Website is on in the popup. Then check Appearance: Follow System only darkens pages when the device itself is in Dark Mode, and Always Light never applies dark themes. Reload the page after changing these settings.

What does Follow System mean?

Follow System uses the selected Duskio theme when the device is in Dark Mode. When the device is in Light Mode, Duskio leaves webpages light.

What does Always Dark mean?

Always Dark keeps supported webpages dark regardless of device appearance. It still respects per-site Off, website access, and sites where Duskio should not restyle the page.

Why don’t themes apply in Always Light?

Always Light leaves webpages light and does not apply dark themes. Your chosen theme stays saved so it is ready when you switch to Follow System or Always Dark.

How do I change themes?

Open the Duskio popup in Safari, or open Theme in the Duskio app. Theme is a global choice: the same palette is used across websites unless a site is turned off. There are 27 built-in themes.

What are Standard, Compatibility, and Safe Mode?

Standard is the best default for most websites. Compatibility is useful when a site has unusual styles or components and keeps more original styling. Safe Mode is a more conservative option for difficult websites and prioritizes usability. Not every website will look perfect in every mode.

How do I disable Duskio for one website?

Open the Duskio popup on that webpage and turn This Website off. The page returns to its own appearance. You can turn it back on later without disabling the extension everywhere.

What does “Fix This Site” do?

If a page looks wrong, open Fix This Site in the popup and choose what you see, such as images, text, background, buttons, layout, or a site that already has dark mode. Duskio then suggests Compatibility, Safe Mode, turning the site off, or restoring Standard. Your selected issue is saved only on this device; nothing is sent.

Troubleshooting

Work through these checks in order before contacting support.

  1. Reload the page. Appearance and permission changes often apply after a refresh.
  2. Confirm the extension is enabled. Open Manage Extensions and make sure Duskio is on.
  3. Confirm website access. Safari must allow Duskio on that domain, or on all websites.
  4. Toggle This Website. Turn it off, reload, then turn it on again from the Duskio popup.
  5. Try Compatibility. Use this when images, logos, or custom components look off.
  6. Try Safe Mode. Use this when layout or controls become hard to use.

Contact

Email support@duskio.net.

When contacting support, please include:

  • iOS or iPadOS version
  • affected website domain
  • selected Duskio mode
  • selected theme

Do not send passwords, private webpage content, account details, or other sensitive information.
